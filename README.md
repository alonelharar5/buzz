# Fina — מנהל הכספים האישי

## מה נבנה
אפליקציית פינטק AI בעברית — קובץ HTML יחיד, עובד ישירות בדפדפן בלי שרת.

## קבצים
- `index.html` — האפליקציה המלאה
- `index.backup.html` — גיבוי

## פתיחה
לחץ פעמיים על `index.html` או הרץ:
```
open /Users/alonel/finance-app/index.html
```

## מה כלול

### Onboarding (12 מסכים)
1. Splash — מסר אחד, כפתור אחד
2. Auth — Apple / Google / טלפון
3. פרופיל: שם, טלפון, תאריך לידה + מזל אסטרולוגי, מדינה
4. שאלות AI (7): מצב פיננסי, הכנסה, התנהלות, מטרות, מנויים, ידע, הוצאות
5. חיבור חשבונות (Apple Pay / כרטיס / בנק)
6. ניתוח אוטומטי עם animation
7. רגע "וואו" — תובנות מותאמות אישית לפי התשובות

### מסכים ראשיים (4)
- **בית** — עדכון חי: יתרה, עסקאות בזמן אמת, AI insights, כפתור "שפר לי את המצב"
- **תלוש** — סורק תלוש שכר עם AI: כל שורה לחיצה להסבר, מצב מתחיל, סימולטור העלאה
- **עסקאות** — פיד חי: כרטיס Mastercard ••••1234, כל עסקה עם תגובת AI
- **מנויים** — זיהוי כפולים, visual anchors, עלות שנתית ו-5 שנים

### פיצ'רים מיוחדים
- **מזל אסטרולוגי** — מחושב מתאריך לידה + אופי כלכלי לפי מזל
- **"לקנות או לא?"** — FAB שמנתח כל רכישה (השפעה חודשית, שנתית, עיכוב מטרות)
- **"שפר לי את המצב הכלכלי"** — 3 פעולות מיידיות עם חיסכון מדויק
- **Toast notifications** — בזמן אמת ("שילמת 120 ₪ בוולט — מעל הממוצע")
- **מצב מתחיל** — שפה פשוטה מאוד בתלוש
- **מצב פוקוס** — תצוגה מינימלית נקייה
- **השוואה לעמיתים** — "80% מהמשתמשים מוציאים פחות ממך על מנויים"
